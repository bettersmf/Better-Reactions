# Better Reactions & Likes

**A powerful reactions and likes system for SMF 2.1.x.**

Better Reactions extends SMF's familiar Like workflow with configurable reactions, categories, presets, topic states, staff-only reactions, member-group permissions, analytics, cleanup tools, and BetterSMF integrations.

> **Keep SMF familiar. Make it better.**

## Current Version

**0.1.0**

Better Reactions v0.1.0 is the current audited stable release.

## Highlights

- Native-style thumbs-up Like experience
- Configurable reactions and reaction categories
- Reaction presets
- Topic states
- Staff-only reactions
- Member-group reaction permissions
- Reaction summaries and member names
- Analytics and profile reaction history
- Orphaned-row cleanup tools
- Better Gallery integration
- Better Chat integration
- Native SMF Like bridge
- Data-preserving uninstall behavior

## Stable Release Hardening

The stable package includes the permission fixes required for normal members to use custom reactions without being incorrectly gated by SMF's native `likes_like` permission, and uses SMF board visibility rules when resolving reaction content.

The release was also audited for package integrity, PHP/JavaScript syntax, language coverage, install/uninstall behavior, permissions, session protection, integrations, and reaction cleanup.

## Compatibility

- Simple Machines Forum **2.1.x**
- PHP 8.x friendly
- Optional Better Gallery and Better Chat integrations activate only when those MODs are installed

## Installation

1. Download the latest package from GitHub **Releases**.
2. In SMF, open **Administration Center → Main → Package Manager → Download Packages**.
3. Upload the Better Reactions ZIP.
4. Install normally.
5. Configure reactions from the Better Reactions administration area.
