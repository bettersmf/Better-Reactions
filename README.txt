Better Reactions & Likes 0.1.0
================================

Target: SMF 2.1.x
Package ID: bettersmf:better-reactions-likes

Overview
--------
Better Reactions & Likes expands SMF's native Like experience with configurable
reactions, reaction categories, presets, topic states, staff-only reactions,
membergroup permissions, analytics, profile history, cleanup tools, and
integrations with other Better SMF packages.

Stable release 0.1.0
--------------------
This package is the stable 0.1.0 public release baseline for the current
Better Reactions feature set. Existing test and release-candidate builds can
upgrade directly to this package without removing reaction history or settings.

Uninstall behavior
------------------
Normal uninstall removes Better Reactions hooks and package files. Reaction
tables, settings, history, and custom icons are preserved unless the native SMF
Package Manager option to remove modification data is selected. When selected,
Better Reactions-owned data is removed by the included uninstall-data routine.

Compatibility
-------------
SMF 2.1.x
